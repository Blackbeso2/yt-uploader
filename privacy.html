Privacy Policy — Yousef Channels Uploader

Last updated: 19 November 2026

Who uses this tool

Yousef Channels Uploader is a private tool used only by the owner of the YouTube channels it uploads to. It is not offered to the public.

Data accessed

With the owner's permission (Google OAuth), the tool uses the YouTube Data API v3 to read the authorized channel's ID and title, upload videos, set thumbnails, add videos to playlists, and read the status of videos it uploaded. It does not access viewers' data, comments, subscribers' personal information, or any other user's data.

Storage

OAuth tokens are stored only on the owner's computer, encrypted with Windows Data Protection (DPAPI). No data is sent to any server other than Google/YouTube. Nothing is sold, shared, or used for advertising.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections. Locally stored tokens are deleted when access is revoked or the tool is removed.
