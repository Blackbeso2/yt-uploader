Yousef Channels Uploader

Yousef Channels Uploader is a private, internal tool used only by the owner of three YouTube channels: أسرار الكون, عجائب الحيوان and نور القصص (Arabic educational channels about space, animals and stories).

The tool runs on the owner's own computer. It uses the YouTube Data API v3 to:

  • upload the owner's own original videos to the owner's own channels,
  • schedule them (private + scheduled publish time),
  • set the video thumbnail and add the video to the channel's own playlists,
  • read the channel ID to make sure the upload goes to the correct channel.

It is not offered to the public, has no other users, and does not access anyone else's data.
